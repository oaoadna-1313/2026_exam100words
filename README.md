## 🌟 核心功能特色

1. **🎴 閃卡翻面記憶特訓模式**：
   - 點擊卡片翻面即刻核對答案（正確國字、注音、詞語釋義、單字解釋）。
   - 「🤔 還不熟」與「😎 學會了」智慧分流，不熟卡片多輪精熟循環。
2. **📝 百題大卷全覽模式**：
   - 支援「✍️ 無解析版（自我測驗）」與「📖 有解析版（講義複習）」。
   - 紅色遮罩點擊即翻開答案；支援「🔀 隨機洗牌」避免死記位置。
3. **📓 LocalStorage 錯題本弱項殲滅庫**：
   - 瀏覽器自動保存個人錯題記錄與「★」星號手動收藏，刷新換頁不遺失。
   - 支援專屬錯題翻卡特訓、錯題測驗、一鍵複製錯題清單給老師或同學討論。
4. **📱 全方位響應式跨載具支援**：
   - 手機、平板、電腦皆可順暢操作，介面典雅精緻。
